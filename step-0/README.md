# Step 0 — Starting from Scratch

Empty directory. Use the prompts to create a Next.js project with Docker Compose and Playwright E2E tests.

## Prerequisites

- Docker Engine + Docker Compose (e.g. [Docker Desktop](https://www.docker.com/products/docker-desktop/), [Podman](https://podman.io/), [Colima](https://github.com/abiosoft/colima))
- An AI coding agent (e.g. [Claude Code](https://claude.ai/claude-code))

## Get Started

Copy the contents of [prompts.md](prompts.md) in this directory and provide them to your AI agent (such as [Claude Code](https://claude.ai/claude-code), [Cursor](https://www.cursor.com/), [GitHub Copilot](https://github.com/features/copilot), or [ChatGPT](https://chatgpt.com/)). If executed correctly, you will have an environment equivalent to step-1 without manual intervention.

**What is Next.js?**

[Next.js](https://nextjs.org/) is a React-based web framework for building full-stack web applications. It provides server-side rendering, file-based routing, and built-in API routes — making it one of the most popular choices for modern web development. In this workshop, we use Next.js as the frontend.

**What are E2E tests?**

E2E (End-to-End) tests simulate real user interactions with your application — opening a browser, clicking buttons, filling in forms, and verifying the results. [Playwright](https://playwright.dev/) is a modern E2E testing framework that automates browser actions. Writing E2E tests ensures that the code generated by the AI agent actually works as expected.

**What are Containers?**

Containers are lightweight, portable packages that bundle your application code with all its dependencies (runtime, libraries, OS tools) so it runs the same way everywhere — your laptop, a colleague's machine, or the cloud. [Docker](https://www.docker.com/) is the most popular tool for building and running containers.

**What is Docker?**

[Docker](https://www.docker.com/) is a platform for building and running containers. You write a `Dockerfile` that describes how to set up your application environment, and Docker builds it into an image that can run anywhere. In this workshop, each service has its own Dockerfile under `Dockerfiles.d/`.

**What is Docker Compose?**

[Docker Compose](https://docs.docker.com/compose/) is a tool for defining and running multi-container applications. You describe all your services (web server, database, test runner, etc.) in a single `compose.yaml` file, then start everything with one command: `docker compose up`. In this workshop, every step uses Docker Compose to run the development environment.

</details>

## Expected Output After Completion

After completing the prompts, you should have a working Next.js project equivalent to step-1:

- `docker compose up` starts the Next.js dev server
- **http://localhost:3000** — Default Next.js "Create Next App" landing page
- `docker compose --profile=e2e-tests run --rm web-e2e-tests` — Playwright E2E tests pass
